# Contestador Inteligente de Glosas — Web

Aplicación Streamlit lista para desplegar.

## Despliegue recomendado
1. Crea un repositorio en GitHub.
2. Sube todo el contenido de esta carpeta.
3. En Streamlit Community Cloud crea una app apuntando a `app.py`.
4. En Settings > Secrets agrega:
   `OPENAI_API_KEY = "tu_clave"`
5. Abre la URL que Streamlit genere.

## Importante
La Resolución 2284 incluida es la fuente normativa inicial. Para producción deben
incorporarse y versionarse los demás manuales, tarifas, normas SOAT y documentos
institucionales que correspondan.

La aplicación no inventa hechos clínicos. La IA puede argumentar con base en la
normativa y en la información de la glosa; los soportes faltantes quedan para
revisión institucional.

No subas datos reales de pacientes a una instancia pública de pruebas hasta
definir controles de acceso, privacidad y almacenamiento adecuados.
